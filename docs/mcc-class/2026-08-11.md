## 1. Collatz — 시뮬레이션

- **문제**: 정수 `n`개 리스트에 절차를 `k`번 반복. 각 원소가 짝수면 `/2`, 홀수면 `3x+1`. 끝난 뒤 전체 합.
- **핵심 아이디어**: 그냥 시키는 대로 `k`번 돌리면 됨. `n·k ≤ 10⁶` 이라 완전 시뮬로 충분. Collatz 특성상 값이 폭발하지 않지만, `3x+1`이 있으니 **`long long`** 안전하게.
- **C++ 풀이**:
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n; long long k;
    cin >> n >> k;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;

    for (long long t = 0; t < k; t++)       // k번 반복
        for (auto& x : a)                    // 각 원소를
            x = (x % 2 == 0) ? x / 2 : 3 * x + 1;

    long long sum = 0;
    for (auto x : a) sum += x;
    cout << sum << "\n";
}
```
- **가르칠 포인트**: "1이 될 때까지"가 아니라 **딱 k번**만 돌린다(멈추면 안 됨). 합이 커질 수 있으니 `int` 대신 `long long`. 이중 반복문 순서(`k`번 바깥, 원소 안쪽).
- **복잡도**: O(n·k) ≤ 10⁶.

## 2. Mobile Game — 그리디 (max-heap)

- **문제**: Alice 파워 `A`, 적 `N`명의 파워 `p_i`. **자기보다 파워가 작은** 적만 처치 가능(처치하면 그 파워만큼 Alice 증가). 파워 `B` 이상 만드는 **최소 처치 수**. 불가능하면 `-1`.
- **핵심 아이디어**: Alice 파워는 계속 **커지기만** 하므로 처치 가능한 적 집합도 커지기만 함. 처치 수를 최소화하려면 **매번 처치 가능한 적 중 가장 큰 놈**을 먹는다(한 번에 최대로 성장). → 정렬 + 포인터로 "지금 처치 가능(`p < cur`)"인 적을 max-heap에 넣고, 가장 큰 것을 꺼내 먹기를 반복.
- **C++ 풀이**:
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>
#include <string>
using namespace std;

int main() {
    int T; cin >> T;
    while (T--) {
        long long N, A, B;
        cin >> N >> A >> B;
        vector<long long> p(N);
        for (auto& x : p) cin >> x;
        sort(p.begin(), p.end());            // 파워 오름차순

        priority_queue<long long> pq;         // 처치 가능한 적들 (max-heap)
        int ptr = 0, kills = 0;
        long long cur = A;
        while (cur < B) {
            // 지금 파워로 처치 가능해진 적을 전부 후보에 추가
            while (ptr < N && p[ptr] < cur) { pq.push(p[ptr]); ptr++; }
            if (pq.empty()) break;            // 더 이상 처치할 적이 없음
            cur += pq.top(); pq.pop();        // 가장 큰 적을 먹어 최대 성장
            kills++;
        }
        cout << (cur >= B ? to_string(kills) : string("-1")) << "\n";
    }
}
```
- **가르칠 포인트**: **왜 가장 큰 적부터?** — 파워는 줄지 않으니, 큰 걸 먼저 먹어도 나중에 작은 걸 못 먹게 되는 일이 없다. 그래서 "매 순간 최대 성장" = 최소 횟수(교환 논증). `<` (strictly less) 조건 — 같은 파워는 못 죽임. 시작부터 `A ≥ B`면 0.
- **복잡도**: O(N log N).

## 3. Innovation — 그리디 + 정렬 (한 장만 특별)

- **문제**: 카드 `n`장, 각 카드 `(a,b,c,d)`. `m`장 골라 일렬로 겹쳐 놓음. **맨 오른쪽(마지막) 카드만 `a,b,c,d` 다 보이고**, 나머지는 `a,b`만 보임. 보이는 수의 합 최대.
- **핵심 아이디어**: 고른 `m`장의 합 = `Σ(a+b)` **＋** 마지막 카드 하나의 `(c+d)`. 마지막 카드는 고른 집합 중 `c+d`가 가장 큰 걸 두면 이득. 즉
  > **답 = max over 크기 m 집합 [ Σ(a+b) + max(c+d) ]**
  - `c+d` **오름차순 정렬** 후, 각 카드 `i`를 "그 집합에서 `c+d` 최대(=마지막)"로 가정. 나머지 `m-1`장은 `i`보다 앞(=`c+d` 작거나 같음)에서 **`a+b` 상위 `m-1`개**를 고름.
  - 진행하며 앞쪽 카드들의 `a+b` 상위 `m-1`개 합을 min-heap으로 유지.
- **C++ 풀이**:
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>
using namespace std;

int main() {
    int n, m; cin >> n >> m;
    vector<pair<long long,long long>> card(n);     // (c+d, a+b)
    for (int i = 0; i < n; i++) {
        long long a, b, c, d; cin >> a >> b >> c >> d;
        card[i] = { c + d, a + b };
    }
    sort(card.begin(), card.end());                // c+d 오름차순

    priority_queue<long long, vector<long long>, greater<long long>> topAB; // a+b 상위 m-1개
    long long sumTop = 0, best = 0;
    for (int i = 0; i < n; i++) {
        long long cd = card[i].first, ab = card[i].second;
        // 이 카드를 '마지막(c+d 최대)'으로: 앞의 상위 m-1개 + 이 카드(a+b+c+d)
        if ((int)topAB.size() >= m - 1)
            best = max(best, sumTop + ab + cd);
        // 이 카드의 a+b 를 다음 후보 풀에 넣기
        topAB.push(ab); sumTop += ab;
        if ((int)topAB.size() > m - 1) { sumTop -= topAB.top(); topAB.pop(); }
    }
    cout << best << "\n";
}
```
- **가르칠 포인트**: 그림에 속지 말 것 — 겹쳐 놓으면 **각 카드는 위(a)·아래왼쪽(b)만 보이고, 맨 끝 카드만 4개 다 보임**. 그래서 `c+d`는 딱 한 장만 산다 → "합 + 한 개만 특별한 최대값" 패턴. 정렬로 "특별한 한 장"을 고정하고 나머지는 상위 `k`개 유지(min-heap). `m=1`이면 그냥 `a+b+c+d` 최대. 값이 크니 `long long`.
- **복잡도**: O(n log n).

## 4. Tichu — 정렬 + 투포인터 (와일드카드)

- **문제**: 카드 `N`장 중 `N-K`장은 수, `K`장은 **와일드(아무 수)**. **연속 수열(run)** `a, a+1, …` 을 가장 길게. 재배열 자유.
- **핵심 아이디어**: 같은 수 중복은 run에 한 번만 쓰이니 **중복 제거**. 정렬된 서로 다른 값 `D`의 창 `[i..j]`를 잡으면, 그 사이 빈칸(내부 gap) = `(D[j]-D[i]) - (j-i)`. 이게 `≤ K`면 와일드로 메꿔 붙일 수 있고, 남는 와일드는 양끝으로 확장 → **run 길이 = (창 크기) + K**. 그러니
  > `(D[j]-D[i]) - (j-i) ≤ K` 인 **가장 큰 창 크기**를 투포인터로 찾고, 답 = `창크기 + K` (최대 `N`).
- **C++ 풀이**:
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    long long N, K; cin >> N >> K;
    int cnt = N - K;
    vector<long long> c(cnt);
    for (auto& x : c) cin >> x;
    sort(c.begin(), c.end());
    c.erase(unique(c.begin(), c.end()), c.end());   // 중복 제거
    int M = c.size();

    long long win = 0;
    int i = 0;
    for (int j = 0; j < M; j++) {
        // 창 [i..j] 내부 빈칸이 K 초과면 왼쪽을 좁힌다
        while (c[j] - c[i] - (j - i) > K) i++;
        win = max(win, (long long)(j - i + 1));
    }
    cout << min(N, win + K) << "\n";                // 실제카드 창 + 와일드 K
}
```
- **가르칠 포인트**: **중복은 쓸모없다**(run엔 각 값 한 번). run 길이 = 실제로 쓴 서로 다른 카드 수 + 와일드 K (내부 gap 메꾸고 남으면 양끝 확장). 와일드가 아주 많으면(`K=N`) 답은 그냥 `N`. 투포인터 이동 조건 `(값차) - (개수차) ≤ K`.
- **복잡도**: O(N log N).

## 5. Rectangles — 구간 분할 DP

- **문제**: x축에 나란히 붙은 빨강 사각형 `N`개(높이 `h_i`, 폭 `w_i`). 파랑 사각형 최대 `K`개로 덮되 **각 빨강은 정확히 한 파랑 안**. 파랑 총면적 최소.
- **핵심 아이디어**: 빨강이 나란히 붙어 있으니 한 파랑은 **연속 구간** `[j..i]`를 덮음. 그 파랑의 폭 = `Σw`, 높이 = `max h` → 면적 = `(Σw)·(max h)`. 빨강을 `≤ K`개 연속 구간으로 분할해 면적 합 최소 → **DP**.
  - `dp[k][i]` = 앞 `i`개를 파랑 `k`개로 덮는 최소 면적. `dp[k][i] = min_{j<i} dp[k-1][j] + cost(j+1..i)`.
  - `K`가 아주 커도 `K = min(K, N)`로 캡(한 개씩 = N개면 충분).
- **C++ 풀이**:
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    long long N, K; cin >> N >> K;
    vector<long long> h(N), w(N);
    for (int i = 0; i < N; i++) cin >> h[i] >> w[i];
    if (K > N) K = N;

    const long long INF = 1e18;
    vector<vector<long long>> dp(K + 1, vector<long long>(N + 1, INF));
    dp[0][0] = 0;
    for (int k = 1; k <= K; k++)
        for (int i = 1; i <= N; i++) {
            long long sumW = 0, maxH = 0;
            for (int j = i; j >= 1; j--) {          // 그룹 [j..i]
                sumW += w[j - 1];
                maxH = max(maxH, h[j - 1]);
                if (dp[k - 1][j - 1] < INF)
                    dp[k][i] = min(dp[k][i], dp[k - 1][j - 1] + sumW * maxH);
            }
        }
    long long ans = INF;
    for (int k = 1; k <= K; k++) ans = min(ans, dp[k][N]);  // 최대 K개
    cout << ans << "\n";
}
```
- **가르칠 포인트**: "각 빨강이 **정확히 한** 파랑" → 파랑들이 빨강을 **연속 구간으로 분할**(겹치면 어떤 빨강이 두 파랑에 들어감). 구간 비용 = `(폭 합)×(최고 높이)`. K가 10⁹라도 N을 넘으면 의미 없음(캡). 면적은 `long long`.
- **복잡도**: O(K·N²) ≤ 200³ ≈ 8×10⁶.

## 6. Sum^k — 부분집합 거듭제곱 DP (이항정리)

- **문제**: 배열 `A`(길이 `N`). 부분집합 `S`의 점수 = `(원소 합)^K`. **모든 비어있지 않은 부분집합** 점수 합을 `mod 998244353`.
- **핵심 아이디어**: 원소를 하나씩 추가하며 `P[t] = (지금까지 부분집합들의 sum^t 합)` 을 `t=0..K` 유지(공집합 포함). 새 원소 `a`를 추가:
  - `a`를 안 넣는 부분집합 → 옛 `P[t]` 그대로.
  - `a`를 넣는 부분집합 → `(옛합 + a)^t = Σ_j C(t,j)·a^{t-j}·(옛합)^j` → 합치면 `Σ_j C(t,j)·a^{t-j}·P[j]`.
  - 따라서 `newP[t] = P[t] + Σ_{j=0}^{t} C(t,j)·a^{t-j}·P[j]`.
  - 답 = `P[K]` (K≥1이면 공집합의 `0^K=0`이라 자동 제외).
- **C++ 풀이**:
```cpp
#include <iostream>
#include <vector>
using namespace std;
const long long MOD = 998244353;

int main() {
    long long N, K; cin >> N >> K;
    // 이항계수 C[t][j]
    vector<vector<long long>> C(K + 1, vector<long long>(K + 1, 0));
    for (int t = 0; t <= K; t++) {
        C[t][0] = 1;
        for (int j = 1; j <= t; j++) C[t][j] = (C[t-1][j-1] + C[t-1][j]) % MOD;
    }
    vector<long long> P(K + 1, 0);
    P[0] = 1;                                   // 원소 0개: 공집합만 (sum=0, 0^0=1)
    for (int e = 0; e < N; e++) {
        long long a; cin >> a; a %= MOD;
        vector<long long> pw(K + 1); pw[0] = 1; // a^0..a^K
        for (int t = 1; t <= K; t++) pw[t] = pw[t-1] * a % MOD;

        vector<long long> np(K + 1);
        for (int t = 0; t <= K; t++) {
            long long with = 0;                 // a를 넣은 부분집합들의 기여
            for (int j = 0; j <= t; j++)
                with = (with + C[t][j] * pw[t-j] % MOD * P[j]) % MOD;
            np[t] = (P[t] + with) % MOD;
        }
        P = np;
    }
    cout << P[K] % MOD << "\n";
}
```
- **가르칠 포인트**: **모든 부분집합을 직접 못 돈다**(2^N). 핵심은 `(옛합+a)^K`를 **이항정리**로 펼쳐 `P[0..K]`만 들고 다니는 것. `P[t]`의 정의(부분집합들의 `sum^t` 합)를 정확히 잡는 게 관건. K≥1이면 공집합은 `0^K=0`이라 답에서 자동으로 빠짐. 매 곱셈마다 `% MOD`.
- **복잡도**: O(N·K²). (N=10⁵,K≤3 / N≤200,K≤200 둘 다 여유.)
