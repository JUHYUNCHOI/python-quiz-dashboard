### 🚨 학생만 찾은 것 — 검토자 둘 다 놓쳤다 (제일 큼)
**마지막 두 쪽에서 완전히 무너진다.** 기획자·수업은 결-c 를 "표준에 맞음 ✅" 로 통과시켰다.
- `isAt = [[[0] * N for _ in range(N)] for _ in range(N)]` — 3중 리스트 컴프리헨션
- `Ms = [i for i in range(N) if (b >> i) & 1]` — 조건 있는 컴프리헨션
- `1 << N` — `>>` 는 그림으로 설명했는데 `<<` 는 설명 없이 "이게 2^N 개예요"
- 학생: *"선생님이 옆에서 리스트 컴프리헨션을 따로 알려주지 않으면 혼자서는 못 풀 것 같다."*
- 파이썬 레슨에 컴프리헨션·비트 연산자는 **안 나온다** (기획자 실측).

> 검토자 둘이 통과시킨 자리를 학생이 무너뜨렸다.
> **화면을 규칙으로 보는 눈과 처음 보는 눈은 다른 것을 본다.** 둘 다 필요하다.

## 2026-09-11 — 코드 주석이 한국어라 영어 학생에게 안 읽힌다 (저장소 전체)

**발견**: student-algorithm 이 moohunt 를 **영어 모드**로 따라가다가 —

Read 토글은 English 로 되어 있었는데 **코드 주석만 한국어**로 나왔다."*

**규모**: quest **93개 · 759줄**. (세는 법: 코드 배열 문자열 중 `#`/`//` 로 시작하고 한글이 든 줄)
가장 많은 곳 — mooin3 50 · printseq 48 · rounding 40 · checkups 33 · reflection 32 · cowphotos 25 · hps 25

**왜 이렇게 되나 (구조)**: 코드 배열(`FULL_PY` · `FAST_CPP` 등)이 `t(E, 영어, 한국어)` 가 아니라
**한 벌뿐**이다. 그래서 언어를 바꿔도 코드 안 주석은 안 바뀐다.
말풍선(`beats`)·설명(`why`)은 이중 언어인데 **코드만 아니다.**

**혼자 정할 일이 아닌 이유**: 셋 중 하나를 골라야 하고 다 비용이 크다.
  (가) 코드 배열을 `(E) => [...]` 로 바꿔 주석을 이중 언어로 — 93개 파일, 🔒 USACO_VERIFIED 다수
  (나) 코드에서 주석을 빼고 말풍선이 다 맡는다 — CodeWalk 표준과는 맞지만 PDF·복사에는 주석이 없어진다
  (다) 영어 트랙에서는 주석만 걷어낸다 — 렌더 단계에서 필터, 파일은 안 건드림
⚠️ 🔒 USACO_VERIFIED 파일이 많아 **선생님 지시 없이는 시작하지 않는다.**
