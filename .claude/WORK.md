### 🚨 학생만 찾은 것 — 검토자 둘 다 놓쳤다 (제일 큼)
**마지막 두 쪽에서 완전히 무너진다.** 기획자·수업은 결-c 를 "표준에 맞음 ✅" 로 통과시켰다.
- `isAt = [[[0] * N for _ in range(N)] for _ in range(N)]` — 3중 리스트 컴프리헨션
- `Ms = [i for i in range(N) if (b >> i) & 1]` — 조건 있는 컴프리헨션
- `1 << N` — `>>` 는 그림으로 설명했는데 `<<` 는 설명 없이 "이게 2^N 개예요"
- 학생: *"선생님이 옆에서 리스트 컴프리헨션을 따로 알려주지 않으면 혼자서는 못 풀 것 같다."*
- 파이썬 레슨에 컴프리헨션·비트 연산자는 **안 나온다** (기획자 실측).

> 검토자 둘이 통과시킨 자리를 학생이 무너뜨렸다.
> **화면을 규칙으로 보는 눈과 처음 보는 눈은 다른 것을 본다.** 둘 다 필요하다.
